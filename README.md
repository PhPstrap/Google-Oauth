# Google OAuth Module for PhPstrap

A Google OAuth login module for PhPstrap that allows users to register and sign in using their Google account.

This module adds a simple Google login flow to PhPstrap and can be used alongside the default email and password login system.

## Features

- Sign in with Google
- Register new users using Google OAuth
- Link Google accounts to existing PhPstrap users
- Configurable Google Client ID and Client Secret
- Secure OAuth callback handling
- Bootstrap-friendly login button
- Easy installation into existing PhPstrap projects

## Requirements

- PHP 7.4 or newer
- PhPstrap installed
- MySQL or MariaDB
- A Google Cloud OAuth Client ID and Client Secret
- HTTPS enabled on your site
